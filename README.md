# VPS Speedcheck

Один Bash-скрипт для быстрой проверки сетевого канала Linux VPS через два независимых инструмента:

- официальный **Ookla Speedtest CLI** — автоматически выбранный ближайший сервер, ping, jitter, packet loss, download и upload;
- **iperf3** — TCP upload/download в 4 потока и в 1 поток через резервируемый список публичных серверов.

Скрипт проверяет наличие инструментов, при необходимости устанавливает их, классифицирует проблемы доступа и выводит одну итоговую сводку. `Connection refused` или `server busy` у публичного iperf3 не объявляется блокировкой VPS: скрипт перебирает другие серверы и порты.

## Быстрый запуск

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/zchk0/speedcheck/main/speedcheck.sh)
```

Если автоустановке нужны права:

```bash
curl -fsSL https://raw.githubusercontent.com/zchk0/speedcheck/main/speedcheck.sh -o /tmp/speedcheck.sh \
  && sudo bash /tmp/speedcheck.sh
```

Локальный запуск:

```bash
chmod +x speedcheck.sh
sudo ./speedcheck.sh
```

## Что происходит

1. Определяются ОС, архитектура, vCPU и RAM.
2. Проверяется, что команда `speedtest` — именно официальный клиент Ookla, а не одноимённый Python-пакет.
3. При отсутствии Ookla CLI загружается официальный статический бинарник для `x86_64`, `aarch64`, `armhf` или `i386`. Если `install.speedtest.net` недоступен, на системах с `apt`, `dnf` или `yum` используется резервный репозиторий `ookla/speedtest-cli` на Packagecloud.
4. Запускается Speedtest в JSON-режиме с лимитом 120 секунд.
5. Ошибки разделяются на блокировку/ограничение, DNS, таймаут и общую недоступность.
6. Проверяется и при необходимости устанавливается `iperf3`.
7. Для каждого iperf3-теста перебираются публичные серверы и порты, пока тест не завершится.
8. Выводится общая таблица и краткая интерпретация результатов.

## Режимы

```text
--quick                   Только многопоточные iperf3 upload/download
--full                    Добавить тесты в один поток (по умолчанию)
--duration SECONDS        Длительность каждого iperf3-теста, по умолчанию 10
--parallel NUMBER         Число потоков, по умолчанию 4
--iperf-server HOST:PORT  Проверять только указанный iperf3-сервер
--no-install              Ничего не устанавливать
--no-color                Отключить цвета
-h, --help                Справка
```

Примеры:

```bash
# Быстрый тест
sudo ./speedcheck.sh --quick

# По 15 секунд, 8 потоков
sudo ./speedcheck.sh --duration 15 --parallel 8

# Свой iperf3-сервер
./speedcheck.sh --iperf-server 203.0.113.10:5201

# Только диагностика, без изменений системы
./speedcheck.sh --no-install
```

## Поддерживаемые системы

- Debian / Ubuntu и производные (`apt-get`)
- Fedora / RHEL / AlmaLinux / Rocky Linux (`dnf` или `yum`)
- Alpine Linux (`apk`)
- Arch Linux (`pacman`)
- openSUSE (`zypper`)

Для автоматической установки требуются `root` или `sudo`. Резервный вариант добавляет в систему репозиторий Ookla на Packagecloud. Ookla Speedtest CLI предназначен для личного некоммерческого использования и запускается с принятием его лицензии и GDPR-условий.

## Как читать результат

- **Ookla** хорошо показывает скорость до автоматически выбранной площадки из сети Speedtest.
- **iperf3, несколько потоков** показывает суммарный потенциал TCP-канала.
- **iperf3, один поток** ближе к возможностям одной TCP-сессии и полезен как ориентир для одного VPN-клиента.
- Разница между Ookla и iperf3 нормальна: используются разные площадки, маршруты, алгоритмы и число соединений.
- Недоступность всех публичных iperf3-серверов не доказывает блокировку. Они допускают ограниченное число одновременных тестов и могут быть заняты.

## Источники серверов

Резервные точки выбраны из публичных iperf3-серверов Европы. Их доступность не гарантируется владельцами и может меняться.
